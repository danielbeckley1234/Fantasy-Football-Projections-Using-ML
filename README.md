# Fantasy Football Projections Using ML

This project uses data from online, public resources and machine learning to predict fantasy football points leaders by position. A detailed report can be found [here](https://docs.google.com/document/d/1dfkJSbxTlx-aM7O0v8DSHmSK4mWflq1XvefCgzUzj00/edit?usp=sharing). 

`data_collection` houses the scripts that generate each position's master dataset, alongside the position-specific target feature map used for the models.
`modeling_scripts` includes scripts that function for feature engineering and model training/testing.
`projections` is filled with a ranked dataset of each position's projected fantasy point leaders for the next season.
